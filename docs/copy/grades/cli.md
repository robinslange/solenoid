### Gate 0: claims the code contradicts

Redemption locks after 5 failed checks in an hour or 10 in a day, and each wrong try counts once per live code (up to 3). With 2 or 3 live codes, 2 wrong tries lock it (`core.ts` `#redeem`). The lock covers the address and purpose, not one code. While it holds, a new code fails too, because `#redeem` checks the fail count before the hash. So the suggested next step fails and spends one of the 5 hourly code requests.
