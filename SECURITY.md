# Security

Report a vulnerability privately to security@solenoid.systems. Say what you found, how to reproduce it, and what it affects. Robin Lange reads the mailbox and replies within 7 days to acknowledge it.

In scope: the API at `api.solenoid.systems` (`worker/`), the packages `@solenoid.systems/sdk`, `@solenoid.systems/cli`, `@solenoid.systems/mcp` and `@solenoid.systems/testing`, and the site at `solenoid.systems`.
